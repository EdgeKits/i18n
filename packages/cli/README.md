# edgekits-i18n

This package exists so that `npx edgekits-i18n` always resolves to the EdgeKits i18n CLI.
It installs [`@edgekits/i18n-core`](https://github.com/EdgeKits/i18n/tree/main/packages/core#readme) and runs its `edgekits-i18n` command.
In a project, install [`@edgekits/astro-i18n`](https://github.com/EdgeKits/i18n/tree/main/packages/astro#readme) or [`@edgekits/tanstack-i18n`](https://github.com/EdgeKits/i18n/tree/main/packages/tanstack#readme) instead.
